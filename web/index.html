Give AI a place to experiment.

RealGrounds rebuilds a real room from one ordinary photo: every object is measured, placed and loaded into a physics engine. An AI agent then works in that copy on its own. It tests each action on a snapshot, keeps only what measurably helps, and stops or asks for help when it should.

Autonomous safety

How it knows when to stop

The AI only proposes. A separate supervisor decides what is tried, what is kept and when to stop, from measurements. It works at three levels: each task, each unattended run, and this app (its Claude budget, top right). Every card below shows its evidence: automated tests and real runs.

Assumptions, failure cases and limitations

  • No real-world validation yet. Every outcome is in a simulated copy of the room.
  • Rooms are simplified. About half of the objects are found, objects are boxes, and one photo shows only part of a room.
  • Masses are catalog typical values ("[typical]"); the heavy box's 40 kg is a test value set by hand.
  • Failure case, our own photo: in a dorm room, Claude wrote 3 tasks. One was already true and two were stopped correctly (no free floor in reach; a bag boxed in), with none solved.
  • A fixed error: one early "impossible" verdict was wrong (reach measured from an object's centre). Reach now uses the body's arm reach, and a test covers it.
  • The loop detector has not triggered in a real run. Loops can't be kept (only measurable improvement is kept), and repeated proposals are refused before they run.
  • Claude's plans vary between runs; the physics does not. That is why solutions are re-checked by replay.

Run it yourself

Reproduce the experiments

Everything on this site comes from code you can run. The three experiments need only the physics engine: no vision models, no GPU. Claude is optional; the fixed-rules planner is free and needs no key.

1

Get the code and install

Tested on macOS (Apple Silicon) with Python 3.14.

git clone <repository URL from our submission> realgrounds
cd realgrounds
python3 -m venv .venv && source .venv/bin/activate
pip install numpy opencv-python pyyaml mujoco anthropic
2

Run the three experiments (about 10 seconds each)

python run_task.py --scene light --planner rules --video   # solved: the box is moved out of the way
python run_task.py --scene heavy --planner rules --video   # stops: 40 kg test box, the arm lifts 15 kg
python run_task.py --scene wall  --planner rules           # stops at once: impossible by geometry

Each run writes outputs/tasks/<scene>/: report.md (every try, what was kept, the supervisor's decision), video.mp4 and stills.png.

3

Let Claude plan (optional)

echo "ANTHROPIC_API_KEY=sk-ant-..." > .env              # stays local, git-ignored
python run_task.py --scene heavy --planner claude --video  # about $0.001 per run with Claude Haiku 5.5

Try the stop rules: --max-tries 1 stops on the attempt limit. Every Claude call is priced and counted; the supervisor stops a task when its budget is spent.

4

Check the claims

pip install pillow matplotlib trimesh
python -m unittest discover -s tests -t .                 # 44 tests, about 7 s, no network, no cost
5

The full app and your own photos

pip install -r requirements.txt                          # plus MoGe-2, see requirements.txt
python app.py                                             # this site, live, at http://127.0.0.1:8000

Rebuilding rooms from photos needs the four vision models in models/ (MoGe-2, SegFormer, Grounding DINO, SAM; about a minute per photo on an M-series Mac). The README lists them. With the app running, every button on this site works: run the experiments live, upload a photo, run the tests.
